# 点云可视化系统 - 快速参考

## 🎮 控制方式

### 鼠标操作
```
左键拖拽    →  旋转视角（CloudCompare 风格）
右键拖拽    →  平移视角
滚轮/中键   →  缩放
Alt + 左键  →  测量模式下临时旋转
```

### 键盘操作
```
W / S       →  前后移动（水平面，不改变高度）
A / D       →  左右移动（水平面，不改变高度）
Q / E       →  上下移动（垂直方向）
Shift +键   →  加速移动（3倍速）
R           →  重置视角
```

## 🔧 关键修复

### v1.3 - 相机缩放重置问题（最新）

**问题**：滚轮缩放后，点击鼠标会重置缩放

**解决方案**：相机状态实时同步
- 每帧检测 HelixCamera 位置变化
- 自动同步到 `_cameraDistance` 变量
- 开销极小（<0.01ms/帧）

**关键代码位置**：
- `MainWindow.xaml.cs` 第152行：注册同步事件
- `MainWindow.xaml.cs` 第990行：`SyncCameraState()` 方法

### v1.2 - 键盘控制优化

**改进**：
- W/S/A/D 只在水平面移动
- Q/E 垂直上下移动
- Shift 加速

**关键代码位置**：
- `MainWindow.xaml.cs` 第381行：`MoveCameraRelative()` 方法

### v1.1 - 黑屏问题

**修复**：
- 添加光源（DirectionalLight3D + AmbientLight3D）
- 点云去中心化处理
- EffectsManager 初始化

## 🎯 常见问题

### Q: 滚轮缩放不工作？
**A**: 
1. 检查 Viewport 是否获得焦点（点击一下视口）
2. 查看日志是否有 "相机同步" 消息
3. 确认已添加 `Focusable="True"` 属性

### Q: 鼠标点击后缩放重置？
**A**: 
1. 检查是否启用了 v1.3 的相机同步机制
2. 查看日志中 Distance 值是否保持不变
3. 确认 `SyncCameraState` 方法正常工作

### Q: 键盘移动方向错误？
**A**: 
1. 确认使用了 v1.2 的 `MoveCameraRelative` 实现
2. W/S 应该只在水平面移动
3. Q/E 应该垂直上下移动

### Q: 黑屏？
**A**: 
1. 检查是否添加了光源（DirectionalLight3D）
2. 确认点云去中心化处理正常
3. 查看日志中的 "几何体更新完成" 消息

## 📊 系统架构

```
MainWindow
├── Viewport3DX (HelixToolkit)
│   ├── PerspectiveCamera (HelixCamera)
│   ├── DirectionalLight3D × 2
│   ├── AmbientLight3D
│   └── PointGeometryModel3D
│
├── 自定义相机状态
│   ├── _cameraYaw (偏航角)
│   ├── _cameraPitch (俯仰角)
│   ├── _cameraDistance (距离)
│   └── _cameraTarget (目标点)
│
├── 事件处理
│   ├── PreviewMouseDown/Up/Move
│   ├── PreviewMouseWheel / MouseWheel
│   ├── PreviewKeyDown
│   └── CompositionTarget.Rendering (同步)
│
└── 日志系统
    ├── 文件输出 (PointCloudApp.log)
    └── VS输出窗口 (Debug.WriteLine)
```
