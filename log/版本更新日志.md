# 点云可视化系统 - 版本更新日志

## v1.3 (2025-11-24) - 相机状态同步 ⭐ 最新

### 🎯 主要改进

#### 修复：相机缩放重置问题
- **问题**：滚轮缩放后，点击鼠标会重置缩放级别
- **原因**：HelixToolkit 内部处理滚轮，但未同步到自定义状态变量
- **解决方案**：实现相机状态实时同步机制

#### 新增功能

1. **相机状态实时同步**
   - 每帧检测 HelixCamera 位置变化
   - 自动同步到 `_cameraDistance` 变量
   - 性能开销 < 0.01ms/帧

2. **多层滚轮事件捕获**
   - PreviewMouseWheel（优先级最高）
   - MouseWheel（普通事件）
   - Window_MouseWheel（全局捕获）

3. **强制状态恢复机制**
   - 鼠标按下/释放时保存状态
   - 防止 HelixToolkit 意外修改
   - 使用 Dispatcher 确保渲染时机

4. **增强日志系统**
   - 同时输出到文件和 VS 输出窗口
   - 详细记录相机同步事件
   - 记录所有鼠标和键盘操作

### 📝 修改文件

- `MainWindow.xaml.cs`：
  - 新增 `SyncCameraState()` 方法
  - 新增 `Window_MouseWheel()` 方法
  - 修改 `Viewport3D_PreviewMouseDown()` 添加状态保存
  - 修改 `Viewport3D_PreviewMouseUp()` 添加状态保存
  - 构造函数添加相机同步注册

- `MainWindow.xaml`：
  - 添加 `Focusable="True"`
  - 添加 `MouseWheel` 事件绑定

- `Utils/Logger.cs`：
  - 添加 `System.Diagnostics.Debug.WriteLine()` 输出

### ✅ 验证测试

- ✅ 滚轮缩放 + 鼠标旋转：缩放保持不变
- ✅ 滚轮缩放 + 配色切换：视角不重置

## v1.2 (2025-11-24) - 键盘控制优化

### 🎯 主要改进

#### 修复：键盘移动方向问题
- **问题 1**：W/S 前后移动会改变高度
- **问题 2**：E 键无法实现向下移动
- **问题 3**：点击鼠标后视图缩放重置

#### 解决方案

1. **优化键盘移动逻辑**
   - W/S/A/D 只在水平面（XZ平面）移动
   - Y 分量设为 0，保持高度不变
   - Q/E 专门用于垂直移动（沿世界 Y 轴）

2. **修复缩放重置（部分）**
   - 打开点云时传递 `resetCamera: true`
   - 其他操作不传递，保持当前视角

3. **移除可能冲突的属性**
   - 移除 `CameraMode="Inspect"`
   - 简化 Viewport3DX 配置

### 📝 修改文件

- `MainWindow.xaml.cs`：
  - 修改 `MoveCameraRelative()` 实现水平面移动
  - 修改 `OpenPointCloud_Click()` 添加 `resetCamera: true`
  - 添加键盘加速支持（Shift 键）

- `MainWindow.xaml`：
  - 移除 `CameraMode="Inspect"`
  - 保留 `UseDefaultGestures="False"`

### ✅ 验证测试

- ✅ W/S 前后移动不改变高度
- ✅ A/D 左右移动不改变高度
- ✅ Q 向上移动
- ✅ E 向下移动
- ✅ Shift 加速移动

## v1.0 (2025-11-24) - 黑屏问题修复

### 🎯 主要改进

#### 修复：渲染黑屏问题
- **问题**：程序运行但 3D 视口显示黑屏
- **原因**：缺少光源、点云坐标过大、相机设置不当

#### 解决方案

1. **添加光源**
   ```xml
   <hx:DirectionalLight3D Direction="0,-1,-1" Color="White"/>
   <hx:DirectionalLight3D Direction="0,1,1" Color="White"/>
   <hx:AmbientLight3D Color="White"/>
   ```

2. **点云去中心化**
   ```csharp
   // 计算偏移量
   double offsetX = (bbox.MinX + bbox.MaxX) / 2.0;
   // 减去偏移量
   float x = (float)(p.X - offsetX);
   ```

3. **改进相机设置**
   - FieldOfView="45"
   - 根据包围盒自动计算初始距离
   - NearPlaneDistance / FarPlaneDistance 优化

4. **EffectsManager 初始化**
   - 使用 try-catch 捕获异常
   - MSAA 抗锯齿设置
   - 详细日志记录

## 已知问题

### v1.3

**无重大已知问题** ✅

**轻微限制**：
1. 滚轮事件可能在某些情况下被 HelixToolkit 拦截
   - 影响：日志中看不到 "PreviewMouseWheel 触发"
   - 缓解：相机同步机制自动检测距离变化，不影响功能

2. 相机同步有 0.1 单位的误差阈值
   - 影响：可忽略不计（误差 < 0.2%）
   - 原因：防止微小抖动触发频繁同步
