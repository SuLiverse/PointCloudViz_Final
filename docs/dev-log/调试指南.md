# 点云可视化系统 - 调试指南

## 问题追踪

### 当前已知问题
1. **按D键时视角会重置**（"物体立马回正"）
2. **鼠标点击时缩放会重置**

---

## 调试步骤

### 1. 运行程序并查看日志

程序会自动记录所有相机操作到日志文件：
- **日志文件位置**: `PointCloudApp.log`（在程序运行目录）
- **日志内容**: 包含所有相机移动、旋转、初始化的详细信息

### 2. 测试步骤

#### 测试 1: D键重置问题
```
1. 运行程序
2. 打开一个点云文件（任意格式）
3. 等待加载完成
4. 按一次 D 键
5. 立即停止程序
6. 打开 PointCloudApp.log 查看最后几行日志
```

**期望日志内容**:
```
[时间] [INFO] 移动相机: F=0.0, R=1.0, V=0.0, Step=0.xxxx, TargetΔ=<x, y, z>
[时间] [INFO] 相机状态: Target=<x, y, z>, Yaw=-45.0°, Pitch=-25.0°, Distance=xxx.xx
```

**如果看到**:
```
[时间] [INFO] 初始化相机: BBox Size=xxx.xx, Distance=xxx.xx
```
说明 D 键触发了相机重新初始化（这是bug）。

#### 测试 2: 鼠标点击重置问题
```
1. 运行程序
2. 打开一个点云文件
3. 等待加载完成
4. 用鼠标滚轮缩放（记住当前视角）
5. 点击鼠标左键或右键拖动
6. 观察是否缩放重置
7. 查看日志
```

**期望**: 只看到旋转或平移日志，不应该看到"初始化相机"日志。

## 已实施的修复

### 修复 1: 彻底禁用 HelixToolkit 内部相机控制

在 `MainWindow.xaml` 中添加了以下属性：
```xml
IsInertiaEnabled="False"
IsChangeFieldOfViewEnabled="False"
IsMoveEnabled="False"
IsPanEnabled="False"
IsRotationEnabled="False"
IsZoomEnabled="False"
```

这些属性确保 HelixToolkit 不会干扰我们的自定义相机控制。

### 修复 2: 添加详细的调试日志

所有相机操作现在都会记录日志：
- `MoveCameraRelative`: 记录移动方向、步长、目标点变化
- `ApplyCameraTransform`: 记录完整的相机状态（Yaw/Pitch/Distance/Target）
- `InitializeCameraFromBBox`: 记录初始化时的包围盒大小和距离

### 修复 3: 键盘移动仅在水平面操作

W/S/A/D 键现在只在水平面（XZ平面）移动，不改变高度：
```csharp
var horizontalForward = new Vector3(cos(yaw), 0, sin(yaw));
var horizontalRight = new Vector3(sin(yaw), 0, -cos(yaw));
```

Q/E 键专门用于垂直移动（沿世界Y轴）。

## 如何查看日志文件

### Windows 方式 1: 记事本
```powershell
notepad PointCloudApp.log
```

### Windows 方式 2: PowerShell 实时监控
```powershell
Get-Content PointCloudApp.log -Wait -Tail 20
```

### Windows 方式 3: 查看最后 50 行
```powershell
Get-Content PointCloudApp.log -Tail 50
```

## 常见日志模式

### 正常的键盘移动
```
[INFO] 移动相机: F=0.0, R=1.0, V=0.0, Step=0.1234, TargetΔ=<0.123, 0, 0.456>
[INFO] 相机状态: Target=<1.23, 0, 4.56>, Yaw=-45.0°, Pitch=-25.0°, Distance=100.00
```

### 正常的鼠标旋转
```
[INFO] 相机状态: Target=<0, 0, 0>, Yaw=-43.2°, Pitch=-26.8°, Distance=100.00
[INFO] 相机状态: Target=<0, 0, 0>, Yaw=-41.5°, Pitch=-28.5°, Distance=100.00
```

### 异常的相机重置（Bug）
```
[INFO] 初始化相机: BBox Size=50.00, Distance=75.00
[INFO] 相机状态: Target=<0, 0, 0>, Yaw=-45.0°, Pitch=-25.0°, Distance=75.00
```

如果在按D键或点击鼠标后看到"初始化相机"日志，说明存在bug。
